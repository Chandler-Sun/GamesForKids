# 📅 时间线复盘工具

一个基于年度时间线的可视化复盘工具，帮助您回顾和分析多年的项目、个人经历或公司发展历程。

## ✨ 主要功能

### 📊 时间线可视化
- **多年视图**：同时查看多年的事件，支持自定义年份范围（2000-2030）
- **季度划分**：按Q1-Q4季度精确标记事件时间点
- **清晰布局**：白板风格设计，字体清晰易读

### 🎯 事件管理
- **持续事件**：用带箭头的线条表示跨时间段的项目或活动
- **里程碑事件**：用圆点标记重要的时间节点
- **颜色标记**：10种颜色可选，用于区分不同类型的事件
- **结果标注**：支持标记事件结果（✓ 好结果 / ✗ 坏结果 / ○ 中性）
- **所见即所得**：通过拖拽直接在时间线上创建事件

### 📝 注释功能
- **年度摘要**：为特定年份添加文字总结
- **垂直标注**：框选多年范围进行阶段性标注
- **事件编辑**：点击选中事件后可编辑名称、修改结果或删除

### 🤖 AI 复盘分析
- **智能分析**：自动分析时间线上的事件分布和趋势
- **洞察报告**：生成包含整体趋势、关键洞察、改进建议和行动计划的报告
- **一键触发**：点击按钮即可获得AI智能分析

### 💾 数据管理
- **自动保存**：数据自动保存到浏览器 localStorage
- **导入导出**：支持 JSON 格式的数据导入和导出
- **撤销重做**：支持 Cmd/Ctrl + Z 撤销，Cmd/Ctrl + Y 重做
- **历史管理**：最多保存50步操作历史

## 🎨 使用方法

### 1. 设置时间范围
在工具栏中设置起始年份和结束年份。

### 2. 添加事件
1. 选择事件类型（持续事件或里程碑）
2. 选择颜色
3. 点击"添加事件"按钮进入添加模式
4. 在画布上拖拽创建持续事件，或单击创建里程碑

### 3. 编辑事件
1. 点击已有事件进行选中
2. 在工具栏中可以：
   - 编辑事件名称
   - 标记结果（好/坏/中性）
   - 删除事件

### 4. 添加注释
- **年度摘要**：点击"📝 年度摘要"按钮，输入年份和摘要文字
- **垂直标注**：点击"📍 垂直标注"按钮，输入起止年份和标注文字

### 5. AI 复盘
点击"🤖 AI 复盘"按钮，系统将自动分析您的时间线并生成洞察报告。

### 6. 数据管理
- **导出**：点击"💾 导出"保存为 JSON 文件
- **导入**：点击"📂 导入"加载之前保存的数据
- **撤销/重做**：使用快捷键 Cmd/Ctrl + Z / Y，或点击工具栏按钮

## 🎯 适用场景

- **项目复盘**：回顾多个项目的时间线，总结成功经验和失败教训
- **个人成长**：记录个人经历的重要事件，规划未来发展
- **公司发展**：梳理公司发展历程，分析关键转折点
- **产品迭代**：追踪产品各版本发布和重要功能上线
- **学习计划**：规划和复盘长期学习路径
- **职业规划**：记录职业发展的重要节点

## 🛠️ 技术特点

- **React + TypeScript**：类型安全的现代前端开发
- **Canvas 绘图**：高性能的图形渲染
- **CSS 模块化**：样式隔离，易于维护
- **LocalStorage 持久化**：无需服务器，数据本地存储
- **响应式设计**：适配不同屏幕尺寸

## 📱 快捷键

- `Cmd/Ctrl + Z`：撤销
- `Cmd/Ctrl + Y` 或 `Cmd/Ctrl + Shift + Z`：重做
- 点击事件：选中/取消选中
- 拖拽：创建持续事件

## 💡 使用建议

1. **定期更新**：建议每季度或每年更新一次时间线
2. **详细记录**：为重要事件添加详细的备注和摘要
3. **颜色分类**：使用统一的颜色系统区分不同类型的事件
4. **定期复盘**：使用AI复盘功能定期分析，获取洞察
5. **备份数据**：定期导出数据进行备份
